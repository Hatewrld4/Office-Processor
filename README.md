# Smart Report Processor 📊

A professional automation tool designed to eliminate manual data entry in office environments. This script automatically consolidates multiple Excel files into a single, comprehensive report, saving hours of tedious work every week.

## ✨ Key Features
- **Batch Processing:** Merges an unlimited number of Excel files instantly.
- **Error-Resistant:** Handles file path logic and data aggregation seamlessly.
- **Easy Deployment:** Compiled into a standalone `.exe` file for non-technical users.
- **Efficiency:** Turns hours of manual data copying into a few seconds of execution.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** `pandas`, `openpyxl`
- **Build Tool:** `PyInstaller`

## ⚙️ How to use
1. Place all your `.xlsx` files into the `reports/` folder.
2. Run the `processor.exe` file.
3. The consolidated file `Final_Report.xlsx` will be generated in the same directory.

## 🚀 Why this tool?
This tool is built for office automation, focusing on data integrity and time efficiency. It is designed to be user-friendly, requiring zero technical knowledge to operate, making it a perfect solution for administrative and accounting tasks.
